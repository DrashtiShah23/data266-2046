# AI Use Appendix

## 1. What I used an assistant for

I used an AI assistant to help review my implementation, organize the written findings, and check whether my notebook satisfied the assignment requirements. I wrote and ran the notebook code myself and verified the attention implementation and outputs using the executed notebook.

## 2. One thing the assistant got wrong

After I reran my prompt engineering experiments, the assistant initially reused word count values from my previous run.

For example, it reported:

Zero Shot: 106.5  
Few Shot: 22.0  
Chain of Thought: 171.0  
Zero Shot CoT: 171.0  
Meta Prompting: 457.5  
Tree of Thoughts: 333.5

These values did not match my latest executed notebook.

## 3. How I found the problem

I compared the findings document against the output table generated by my rerun. The notebook showed different average word counts:

Zero Shot: 98.0  
Few Shot: 23.5  
Chain of Thought: 130.0  
Zero Shot CoT: 187.0  
Meta Prompting: 413.5  
Tree of Thoughts: 325.0

The model outputs themselves were valid, but the written report had become inconsistent with the latest run.

## 4. What I changed and why

I replaced the old word count values in both the notebook markdown and the findings document with the values from the latest executed run.

I also removed a statement saying Meta Prompting was more than twenty times longer than Few Shot because that comparison was no longer correct after rerunning the prompts.

The corrected version now uses the numbers directly produced by the submitted notebook, so the written interpretation is consistent with the executed outputs.
