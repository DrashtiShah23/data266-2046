# AI USE

## Tool Used

ChatGPT was used as a support tool while completing GPU Assignment 1.

## Where I Used AI

I used ChatGPT mainly to help me understand the assignment requirements, organize the experiment plan, find relevant technical documentation, and review my implementation before running it on the lab GPU.

### Part A: GPU provenance and hardware information

I used ChatGPT to help identify which hardware details needed to be captured from `nvidia-smi -q`, including the GPU UUID, driver version, CUDA version, VRAM capacity, and power limit.

I also used it to help locate the types of vendor documentation I needed for the assigned GPU, such as NVIDIA architecture documentation and product specifications for memory type, memory bandwidth, Tensor Core generation, and supported reduced precision formats.

The final hardware values used in the assignment were taken from the actual lab machine and vendor documentation, not generated by AI.

### Part B: Precision and throughput

I used ChatGPT to review the benchmarking approach for dense matrix multiplication in FP32, TF32, FP16, and BF16.

It helped me check the throughput calculation based on matrix multiplication work, where an N by N matrix multiplication is treated as approximately 2N^3 floating point operations.

I also used it to review the use of CUDA events, warmup iterations, repeated measurements, synchronization, and the calculation of achieved TFLOPS as a percentage of theoretical peak.

The actual timing values and TFLOPS reported in the assignment were produced by my own benchmark runs on the reserved GPU.

### Part C: Memory bound and compute bound operations

I used ChatGPT to help distinguish between memory bound and compute bound workloads and to review the arithmetic intensity calculations.

It helped me reason about why a large memory copy has very low arithmetic intensity while a large matrix multiplication has much higher arithmetic intensity.

I also used it to check the effective memory bandwidth calculation and how to compare the measured result with the GPU vendor bandwidth specification.

### Part D: Attention cost

I used ChatGPT to review the implementation structure for naive scaled dot product attention and PyTorch fused attention.

It helped me verify the tensor operations for QK transpose, scaling by the square root of the head dimension, causal masking, softmax, and multiplication by V.

I also used it to review how to measure peak CUDA memory, latency, sequence length scaling, and how to refine the out of memory boundary rather than claiming an exact token limit without testing it.

For the fused implementation, I used PyTorch `scaled_dot_product_attention` and compared it against the naive implementation.

The sequence length results, memory usage, latency measurements, speedups, and out of memory boundaries came from my own GPU runs.

### Part E: Sustained load and thermal behavior

I used ChatGPT to help plan the 20 minute sustained load experiment and the telemetry collection.

It helped me identify the required values to sample every 5 seconds, including GPU clock, memory clock, temperature, power draw, power limit, and GPU utilization.

I also used it to help organize plots for clock and temperature, power and utilization, throughput over time, and the comparison between the first 30 seconds and the final 5 minutes.

A correlation heatmap was added as an extra visualization to make the thermal and performance relationships easier to inspect.

All telemetry and throughput values were collected from the actual GPU during the run.

### Part F: Reporting and repository organization

I used ChatGPT to help organize `METRICS.md`, `RUN_LOG.txt`, the result tables, generated figures, and the repository folder structure.

I also used it to check that each measurement could be traced back to the GPU UUID recorded in the run log.

## Resources AI Helped Me Identify

AI was used to point me toward the following types of resources:

1. NVIDIA official GPU product specifications
2. NVIDIA GPU architecture documentation
3. PyTorch CUDA documentation
4. PyTorch CUDA Event timing documentation
5. PyTorch CUDA memory statistics documentation
6. PyTorch `scaled_dot_product_attention` documentation
7. PyTorch matrix multiplication precision settings documentation

I used those sources to verify implementation details and hardware specifications rather than treating AI responses as the source of record.

## What AI Did Not Do

AI did not generate the measured benchmark results.

AI did not provide the GPU UUID.

AI did not provide the actual `nvidia-smi -q` output.

AI did not generate the thermal log.

AI did not determine the out of memory boundary without testing.

AI did not generate the final throughput, bandwidth, latency, temperature, power, or utilization measurements.

Those values came from my own execution on the reserved lab GPU.

## Verification

Before including results in the submission, I checked that the notebook outputs, CSV files, figures, `METRICS.md`, and `RUN_LOG.txt` were consistent with the measurements produced during the GPU run.
